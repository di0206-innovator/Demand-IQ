# DemandIQ Streamlit Dashboard

This directory houses the interactive web application for DemandIQ.

## Structure (Planned for Phase 4)
- `main.py`: Primary Streamlit application entrypoint.
- `components/`: UI cards, charts (Plotly), forecast summary cards, and inventory recommendation views.

## Running Locally (when implemented)
```bash
uv run streamlit run app/main.py
```
