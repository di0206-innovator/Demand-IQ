# Processed Data Directory

This directory stores intermediate and finalized processed datasets produced by the DemandIQ pipeline.

## Contents
Processed datasets are generated by running:
```bash
uv run python -m demandiq.data
```
or via the model preparation pipeline.

## Standard Artifacts
- `merged_features.parquet` (or `.csv`): Cleaned and merged master dataset containing transaction logs, center metadata, meal metadata, and engineered temporal lag features.
- `train_split.parquet`: Historical training split adhering to strict temporal cutoff.
- `val_split.parquet`: Validation split for hyperparameter tuning.
- `test_split.parquet`: Hold-out test split for final out-of-time evaluation.

## Hygiene
- Processed data files are excluded from Git version control.
- All transformations are fully deterministic and reproducible from raw files using the `demandiq` package.
